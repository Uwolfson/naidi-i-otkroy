# Найди и открой — прототип

Прототип игровой петли для детской игры-угадайки (1–3 года), планшет.

**Играть:** https://uwolfson.github.io/naidi-i-otkroy/

Один самодостаточный HTML-файл: ни сборки, ни зависимостей, ни сети
(кроме шрифтов, без которых страница тоже работает).

## Что проверяет прототип

- Голос просит найти предмет; верный ответ запускает фирменную анимацию
  (вертолёт взлетает, собака убегает и возвращается, мяч катится).
- Неверный ответ не наказывает: предмет называет себя, вопрос повторяется,
  подсказка придвигается ближе.
- Четыре верных ответа подряд → падает коробка. Четыре стука по коробке →
  новый предмет уходит на полку **и в пул угадывания**.
- Три возрастных режима, переключатель «реалистично / мультяшно».
- Родительские настройки открываются удержанием шестерёнки, а не тапом.

## Ограничения прототипа

Предметы — временные эмодзи вместо 2D-ассетов, голос — синтез речи браузера
вместо записи живой актрисы. Проверяется поведение ребёнка, а не картинка.
Русский голос берётся из системы: на iPad есть всегда, на части Android
может отсутствовать — тогда озвучка пропадёт, механика останется.

Прогресс коллекции хранится в localStorage того браузера, где открыли.

## Откуда берутся картинки и звуки

Картинки и записи — с Pixabay, лицензия Pixabay Content License: свободно,
в том числе коммерчески, без указания авторства. Платные стоки, перезаливки
и сайты, где лицензия не видна, не используются.

- `tools/art.py <id> <url>` — скачать фотографию, снять фон, вписать в
  квадрат 640. Ключ `--crop` вырезает нужный экземпляр, когда предмет снят
  в куче, `--model` меняет модель (для человека нужна портретная).
- `tools/trim.py <файл.mp3> <начало> <длительность>` — оставить в записи
  только те секунды, которые игра успевает проиграть. Режет по границам
  кадров, без перекодирования.
